# 5-day compress (instructor)

Do **not** delete day folders. Skip or homework the struck items.

| Calendar day | Combine | Cut if short |
|--------------|---------|----------------|
| 1 | Git + Dockerfile (Day 1) | Multi-stage Go lab if timeboxed |
| 2 | Compose + Terraform Docker (Day 2) | Second worker exercise |
| 3 | k3s + Helm (Days 3–4) | Terraform k8s provider; Helm rollback homework |
| 4 | CI + GitOps + Vault lite (Days 5–6) | Nexus UI; Maven **or** Gradle not both |
| 5 | Edge + scanners + mini-capstone (Days 7–8) | Cloudflare Tunnel; kube-bench |

Capstone Track A (Compose) is the default on 5 days. Track B if the VM was ready on calendar day 3.

**Day 9 (mobile)** does not fit a 5-day compress. Offer it as an evening / follow-up workshop (Expo Go + LAN origin is enough).
